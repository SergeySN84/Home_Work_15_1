# Проект с описанием основных сущностей и инициализации объектов будущего проекта.

В этом проекте будет реализовано ядро для программы системы платежей.
В дальнейшем для этого ядра возможно будет реализовать любой интерфейс — от сайта до телеграм-бота.
На данном этапе реализована функциональность множественно-го наследования с помощью
абстрактных классов и класса-миксин.
